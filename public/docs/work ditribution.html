Architecture & Distribution Strategy

This document ensures an exactly equal workload across all 13 developers by explicitly mapping every single feature (43 Web, 43 App, 24 Backend Endpoints). We are utilizing a strict Modular Monolith / Feature-Based Architecture.

Zero-Conflict Rule: Each developer is assigned their own specific feature modules (e.g., modules/tasks/). A developer must place their models, controllers, routes, or UI components strictly inside their assigned module folder. No developer is permitted to write outside their module.
