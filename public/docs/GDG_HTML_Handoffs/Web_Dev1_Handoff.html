2. Global Naming & Data Integration Dictionary

To ensure your frontend connects perfectly with the Backend (Node.js/Express) developers, you MUST strictly use these exact JSON keys when sending/receiving data:

  • Identifiers: Always use userId, taskId, meetingId. NEVER use _id directly in components without mapping it first.
  • Response Format: The backend will always respond with this structure. You must check response.success before using data:
    • Success: { "success": true, "data": { ... } }
    • Error: { "success": false, "message": "error string" }
  • Enums: Database statuses are lowercase ("active", "pending"). Your UI components should capitalize them for display (e.g., Pending).

3. Feature Breakdown & Component Logic

Feature 1: Dashboard (W01 - W07)

The Dashboard is the first page the user sees after logging in. It aggregates data from multiple modules.

Required Components (dashboard/components/):

  1. WelcomeBanner.jsx (W01):
    • Logic: Reads user.name from the global auth state or local storage to display "Welcome back, [Name]!".
  2. StatsGrid.jsx (W02):
    • Logic: Displays 4 summary cards: "Active Tasks", "Pending Leaves", "Upcoming Meetings", "Completed Works".
    • Data Source: Calls GET /api/users/me/stats (Backend Dev 1 will provide this endpoint).
  3. TodayMeetingCard.jsx (W03):
    • Logic: Highlights the very next upcoming meeting for today with a "Join Now" button linking to the meeting URL. If no meetings today, display a generic illustration.
  4. MyTasksList.jsx (W04):
    • Logic: A condensed list of the top 3 highest-priority tasks assigned to the current user. Should show task title and due date. Clicking a task routes to the Tasks module.
  5. QuickActions.jsx (W05):
    • Logic: Floating or sticky buttons for rapid actions: "Apply Leave", "Create Task". These should open Modals.
  6. UpdatesGraph.jsx (W06):
    • Logic: A line or bar chart showing the team's activity over the week. You can use a library like recharts or chart.js.
  7. GlobalSearchBar.jsx (W07):
    • Logic: A search input at the top of the dashboard. When typing, it should debounce for 300ms, then call GET /api/users/directory?search=....

Example Dashboard Custom Hook (dashboard/hooks/useDashboardData.js):

import { useState, useEffect } from 'react';
import { fetchDashboardStats } from '../api/dashboardApi';

export const useDashboardData = (userId) => {
    const [stats, setStats] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const loadData = async () => {
            try {
                setLoading(true);
                const response = await fetchDashboardStats(userId);
                if (response.success) {
                    setStats(response.data);
                } else {
                    setError(response.message);
                }
            } catch (err) {
                setError("Failed to fetch dashboard data.");
            } finally {
                setLoading(false);
            }
        };
        loadData();
    }, [userId]);

    return { stats, loading, error };
};

Feature 2: Leave Application Management (W21)

This page allows users to see their past leave requests and submit new ones.

Required Components (leaves/components/):

  1. LeaveHistoryTable.jsx:
    • Logic: A table showing Date, Reason, and Status. Status should have color badges (Green for approved, Red for rejected, Yellow for pending).
    • API Connection: Calls GET /api/leaves/my-leaves (Backend Dev 2).
  2. ApplyLeaveForm.jsx:

    • API Connection: Submits a POST request to /api/leaves (Backend Dev 2). Upon success, trigger a toast notification and refresh the history table.

4. Cross-Team Integration Points (Crucial)

As a Web Frontend Developer, you need to use utilities built by others. Follow these strict rules to avoid bugs:

1. Global API Client (shared/api/apiClient.js)

  • Do NOT write raw fetch() calls containing Authorization: Bearer <token> in every single file.
  • The project architect will create a shared apiClient.js (using Axios) in the shared/ folder. This client will automatically attach the JWT token to every request.
  • You must import and use this client in your api/ folders.
  • Example:
    import apiClient from '../../shared/api/apiClient';

export const submitLeave = async (leaveData) => {
    const response = await apiClient.post('/api/leaves', leaveData);
    return response.data;
};

2. State Management (Authentication)

  • You do not need to write the Login Page (Web Dev 4 is doing that).
  • However, your Dashboard needs to know who is logged in. You will consume a global Context/Zustand store (e.g., useAuthStore()) to get the userId and token.

3. Shared Components

  • Do not build your own basic Buttons, Modals, or Loaders from scratch if they exist in the shared/components/ folder. Always check the shared repository first to maintain consistent UI styling across the entire app.
