2. Global Naming & Data Integration Dictionary

To ensure your mobile app connects perfectly with the Backend (Node.js/Express) developers, you MUST strictly use these exact JSON keys when serializing/deserializing Data Models:

  • Identifiers: Always map userId, roleId, channelId, messageId correctly in your .fromJson() methods. NEVER use _id directly in UI.
  • Response Format: The backend will always respond with this structure. Ensure your repository layer checks response['success']:
    • Success: { "success": true, "data": { ... } }
    • Error: { "success": false, "message": "error string" }

A full-fledged internal messaging system.

Required Widgets (screens/ChatScreen.dart & components/):

  1. ChannelsDrawer:
    • Logic: A side drawer listing available "Channels" (e.g., #general) and Direct Messages.
  2. ChatMessagesListView (A42):

  3. MessageInputField (A43):
    • Logic: A TextField at the bottom. Tapping "Send" emits a send_message socket event. Include an icon to pick images (image_picker).
  4. TypingIndicatorBubble:
    • Logic: Listens for user_typing socket events and displays a subtle Lottie animation or text.

Example Socket Provider (providers/chat_provider.dart):

import 'package:flutter/material.dart';
import 'package:socket_io_client/socket_io_client.dart' as IO;
import 'package:shared_preferences/shared_preferences.dart'; // Or flutter_secure_storage

class ChatProvider extends ChangeNotifier {
  IO.Socket? socket;
  List<dynamic> messages = [];

  void initSocket(String channelId, String token) {
    socket = IO.io('https://api.yourdomain.com', <String, dynamic>{
      'transports': ['websocket'],
      'autoConnect': false,
      'extraHeaders': {'Authorization': 'Bearer $token'}
    });

    socket!.connect();

    socket!.onConnect((_) {
      socket!.emit('join_channel', {'channelId': channelId});
    });

    socket!.on('receive_message', (data) {
      messages.insert(0, data); // Insert at 0 because ListView is reversed
      notifyListeners();
    });
  }

  void sendMessage(String channelId, String text) {
    socket?.emit('send_message', {'channelId': channelId, 'text': text});
  }

  @override
  void dispose() {
    socket?.disconnect();
    super.dispose();
  }
}
