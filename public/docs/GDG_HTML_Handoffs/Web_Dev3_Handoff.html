2. Global Naming & Data Integration Dictionary

To ensure your frontend connects perfectly with the Backend (Node.js/Express) developers, you MUST strictly use these exact JSON keys:

  • Identifiers: Always use userId, meetingId, formId. NEVER use _id directly in components without mapping it.
  • API Response Format: You must check response.success before using data:
    • Success: { "success": true, "data": { ... } }
    • Error: { "success": false, "message": "error string" }

3. Feature Breakdown & Component Logic

Feature 1: Meeting Management (W14 - W18)

This module handles scheduling, viewing, and joining live meetings (via an external link or iframe like Stream/LiveKit).

Required Components (meetings/components/):

  1. MeetingDashboard.jsx (W14) & MeetingFilters.jsx (W16):
    • Logic: Displays a grid or list of upcoming meetings. Needs a filter to toggle between "Upcoming", "Past", and "My Meetings".
    • API Connection: Calls GET /api/meetings?filter=... (Backend Dev 4).
  2. CreateMeetingModal.jsx (W15):
    • Logic: A form for admins to schedule a meeting. Fields: title, description, startTime, endTime, attendees (multi-select dropdown).
    • API Connection: Submits POST /api/meetings.
  3. SummaryAndAttendance.jsx (W17):
    • Logic: A detailed view for a specific meeting. Admins can see a checklist of invited attendees and mark them as present or absent.
    • API Connection: Submits PUT /api/meetings/:meetingId/attendance.
  4. JoinMeetingButton.jsx (W18):
    • Logic: If the current time is close to startTime, this button becomes active. Clicking it should open a new tab or trigger a modal containing the video calling interface (Stream/LiveKit logic).

Example API Hook (meetings/hooks/useMeetings.js):

import { useState, useEffect } from 'react';
import apiClient from '../../../shared/api/apiClient';

export const useMeetings = (filter) => {
    const [meetings, setMeetings] = useState([]);
    const [loading, setLoading] = useState(true);

    useEffect(() => {
        const fetchMeetings = async () => {
            setLoading(true);
            try {
                const response = await apiClient.get(`/api/meetings?filter=${filter}`);
                if (response.data.success) {
                    setMeetings(response.data.data);
                }
            } catch (err) {
                console.error("Failed to fetch meetings");
            } finally {
                setLoading(false);
            }
        };
        fetchMeetings();
    }, [filter]);

    return { meetings, loading };
};

Feature 2: Dynamic Forms (W23 - W26)

This module allows users to see forms created by Admins and submit responses dynamically. (Note: Admin form creation is handled by Web Dev 5, you only handle the filling part).

Required Components (forms/components/):

  1. ActiveFormCards.jsx (W23):
    • Logic: A grid of cards showing available forms (e.g., "Monthly Feedback", "Event Registration").
    • API Connection: GET /api/forms/active (Backend Dev 2).
  2. FormInstructions.jsx (W25):
    • Logic: Displays a markdown or rich-text block explaining the rules of the form before the user starts filling it out.
  3. DynamicFormFillup.jsx (W24):
    • Logic: Extremely important component. It receives a JSON array of fields from the backend (e.g., [{ type: 'text', label: 'Name' }, { type: 'dropdown', options: ['A', 'B'] }]) and dynamically renders the corresponding React inputs (input, select, textarea).
    • State Management: Use a single state object to hold all responses: const [responses, setResponses] = useState({}). Update the object based on input names.
    • API Connection: Submits POST /api/forms/:formId/submit.
  4. FormResponsesDashboard.jsx (W26):
    • Logic: (For Admins Only). A table view showing all submissions for a specific form. You must conditionally render this based on the user's role (check the global auth state).

4. Cross-Team Integration Points (Crucial)

As a Web Frontend Developer, you need to use utilities built by others. Follow these strict rules to avoid bugs:

1. Global API Client (shared/api/apiClient.js)

  • Do NOT write raw fetch() calls containing Authorization: Bearer <token> in every single file.
  • The project architect will create a shared apiClient.js (using Axios) in the shared/ folder. This client will automatically attach the JWT token to every request.
  • You must import and use this client in your api/ folders.

2. Video Calling Integration (Stream/LiveKit)

  • For the JoinMeetingButton, you will likely be embedding a third-party SDK for the video call. Keep all related UI code strictly inside dev3_meetings_forms to prevent bloating the rest of the application.

3. Shared Components

  • Use standard UI elements (Inputs, Dropdowns, DatePickers) from the shared/components/ library so that your Dynamic Forms match the styling of the rest of the application perfectly.
